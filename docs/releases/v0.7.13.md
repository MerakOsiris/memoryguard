# MemoryGuard v0.7.13

## Mandatory-rule replacement and publication budgets

Mandatory-rule updates validate the final rule package with the same audience
matching, canonical-head selection, deduplication, sensitivity checks, and
`ContextBudget` used by bootstrap. A replacement counts the resulting package,
not both the previous and replacement bodies. Equivalent unlocked predecessors
in the same audience and injection policy retire with the replacement; locked,
conflicting, or differently scoped rules remain intact.

Related replacements, supersession links, revisions, evidence projection, and
governance receipts share one SQLite transaction. A handled validation failure
or budget rejection rolls the complete request back, including its idempotency
claim. Shared updates also check affected peers' private mandatory packages.
See [Mandatory rule replacement and recovery](../mandatory-rule-replacement.md)
for the supported recovery and preview flow.

## Agent identity and provider repair

Native `agent` and `group` audience matching and deduplication no longer split
the same audience solely by provider or runtime role. Distinct Agent identities
remain separate, and project-scoped audiences remain project-specific. Provider
repair selects the target provider's verified Agent identity instead of
reusing the calling provider's identity. Unresolved historical identities stay
separate until evidence supports an attribution.

## Conflict readability and atomic resolution

Conflict results keep peer members readable and distinguish groups that can be
resolved from ambiguous groups. Resolving a conflict preserves external peer
groups and does not rewrite their history. Losers are tombstoned as part of the
resolution; protected mandatory rules keep their confirmation requirement.
Failure in the atomic memory operation rolls the resolution back as a whole.

## Cursor Hook timeout

Cursor MemoryGuard Hooks use a 30-second timeout and retain
`failClosed: true`.

## Release status

This source release note does not claim completion of the full CI suite or
publication to PyPI.
